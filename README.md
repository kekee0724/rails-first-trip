# rails-first-trip · A Java engineer learning Rails

I have 6+ years of Java/Spring Boot backend experience. "Languages are
interoperable" is something I believe in practice — I recently completed a
.NET → Java migration solo, and this repo documents my Rails journey the same
way: by building, comparing, and writing down gotchas.
